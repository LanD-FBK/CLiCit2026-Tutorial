This repository hosts the materials for the CLiC-it 2026 tutorial ****Counterspeech Against Hate and Misinformation: An NLP Perspective****.

> ⚠️ **Content warning:** this tutorial is about countering hate speech and misinformation, so some materials contain examples of hateful and/or false statements.

## 🔗 Related resources from the LanD group

Tools and datasets from our team that pair well with this tutorial:

| Resource | Description | Link | Paper |
|---|---|---|---|
| **VERMOUTH** | `claim-article-verdict triplets for verdict generation written in SMP style.` | [`marcoguerini/VerMouth`](https://github.com/marcoguerini/VerMouth/) | https://aclanthology.org/2023.emnlp-main.703.pdf |
| **EUROVERDICT** | `A manually curated multilingual dataset for verdict generation.` | [LanD-FBK/EuroVerdict](https://github.com/LanD-FBK/EuroVerdict) | https://aclanthology.org/2025.findings-acl.853.pdf |
| **CONAN** | Multilingual expert-based HS/CN pairs dataset on Islamophobia. | [`marcoguerini/CONAN`](https://github.com/marcoguerini/CONAN#conan) | https://aclanthology.org/P19-1271.pdf |
| **Multitarget-CONAN** | HS/CN pairs dataset covering multiple targets of hate. | [`marcoguerini/CONAN`](https://github.com/marcoguerini/CONAN#multitarget-conan) | https://aclanthology.org/2021.acl-long.250.pdf |
| **DIALOCONAN** | A multi-turn HS/CN dialogue dataset. | [`marcoguerini/CONAN`](https://github.com/marcoguerini/CONAN#dialoconan) | https://aclanthology.org/2022.emnlp-main.549.pdf |
| **Knowledge-grounded hate countering dataset** | HS/CN pairs with the background knowledge corresponding to the CN | [`marcoguerini/CONAN`](https://github.com/marcoguerini/CONAN#knowledge-grounded-hate-countering-dataset) | https://aclanthology.org/2021.findings-acl.79.pdf |
| **ML-MTCONAN-KN** | A multilingual expansion of Multitarget-CONAN with background knowledge sentences. | [`LanD-FBK/ML_MTCONAN_KN`](https://huggingface.co/datasets/LanD-FBK/ML_MTCONAN_KN) | https://aclanthology.org/2025.mcg-1.10/ |
| **Pairs dataset against hate and misinfo** | HS + misinfo and CS pairs dataset. | [`LanD-FBK/counterspeech_against_hate_and_misinfo`](https://github.com/LanD-FBK/counterspeech_against_hate_and_misinfo#pairs-with-fact-checking-ngo-and-mixed-strategy-cs) | https://arxiv.org/pdf/2605.22435 |
| **CATCH-ME** | A multi-turn HS+misinfo and CS dataset. | [`LanD-FBK/counterspeech_against_hate_and_misinfo`](https://github.com/LanD-FBK/counterspeech_against_hate_and_misinfo#catch-me) | https://arxiv.org/pdf/2606.20369 |
